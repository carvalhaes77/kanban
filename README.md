# Kanban TI Visível — Demonstração

Portfólio de **Renato Carvalhaes**.

Quadro Kanban de TI visível, com WIP, relatório de 5 linhas, modo TV, SLA em Aguardando e histórico leve. Há um modo **Compartilhado opcional** (off por padrão) com Python + SQLite no host.

## Como usar

1. Abra [`kanban-ti-visivel-demo/index.html`](kanban-ti-visivel-demo/index.html)  
   ou leia o [manual do quadro](kanban-ti-visivel-demo/README.md).
2. Individual: sem instalação (abrir o HTML; Windows/Mac/Linux).
3. Uso completo: **Subir Kanban** (Windows) ou **Subir-Kanban.command** (Mac) → Parâmetros → **Gerar chave e ativar**.
4. Detalhes Windows/Mac: [manual do quadro](kanban-ti-visivel-demo/README.md).
